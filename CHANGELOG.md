# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-08-30

### English

- Initial public release of Study Sprint Mobile.
- Added source-material inventory, paper-and-answer pairing, deterministic text extraction, optional OCR, and language detection.
- Added source-grounded knowledge cards and objective quizzes with validation rules.
- Added a responsive offline HTML app with wrong-answer retry and local progress tracking.
- Added seven verified mobile UI previews from a real generated app, including answer feedback, mistake retry, and progress tracking.
- Added a mandatory sample-approval gate before full generation and a separate authorization gate before publishing source-derived content.
- Added English-first bilingual documentation and PolyForm Noncommercial 1.0.0 licensing.

### 中文

- 首次公开发布“抱佛脚·手机复习工具”。
- 提供资料盘点、试卷与答案配对、确定性文字提取、可选 OCR 和语言检测。
- 提供来源可追溯的知识卡片、客观题及数据校验规则。
- 提供适配手机的离线 HTML 应用，支持错题重做和本机进度记录。
- 提供来自真实生成成品的七张手机界面预览，包括答错解析、错题重练和学习进度。
- 完整生成前必须先确认小样；发布含源资料内容的网页前必须另行授权。
- 提供英文优先的双语文档，并采用 PolyForm Noncommercial 1.0.0 非商业许可。
